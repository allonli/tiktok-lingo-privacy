TikTok Lingo 隐私政策

生效日期：2026-09-14

我们处理什么

扩展仅在 TikTok 页面读取当前视频标识、原生字幕地址、字幕文本与时间，提供字幕显示和点击跳转。视频标识用于区分当前视频，不发送给翻译服务商。

翻译数据的去向

只有在你填写接口并明确开启翻译后，原字幕文本与目标语言才会通过 HTTPS 发送到你指定的 OpenAI 兼容 API 服务商。API Key 只用于向该服务商验证身份。TikTok Lingo 不设中转服务器，不接收或出售字幕、密钥或使用数据。服务商如何处理数据由其隐私政策决定。

本机存储

接口地址、模型名称、语言选择与功能开关保存在本机扩展存储。API Key 只存于浏览器会话存储，重启浏览器，或重新加载、更新、停用扩展后清除。字幕与翻译仅在内存中短暂缓存；页面关闭、扩展后台终止后会清除。你可在设置弹窗清除密钥，卸载扩展会移除扩展设置。

权限与范围

TikTok 访问权限用于读取视频字幕和调整播放器布局。自定义接口权限在保存设置时按服务商域名单独申请。扩展不读取密码、私信、浏览历史、支付信息，不上传视频或音频，不含广告、追踪或数据分析服务。

数据使用限制

TikTok Lingo 对接收数据的使用和转移遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。数据仅用于用户可见的字幕功能，不用于广告、画像、信用评估或出售。
